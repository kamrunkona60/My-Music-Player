# My Music Player

An Android offline music player built with Kotlin, Jetpack Compose and AndroidX Media3.

## Current starter features
- Scans local music files after permission is granted
- Background playback service
- Library, all-songs playlist, mini-player and full player screen
- Dark/light theme toggle
- Next/previous playback controls and shuffle/repeat UI
- Equalizer panel UI (real audio effect is not implemented yet)

## Build APK online
1. Open the Actions tab in this repository.
2. Select Build My Music Player APK.
3. Wait for the workflow to finish successfully.
4. Open the completed run and download the `my-music-player-debug-apk` artifact.
5. Extract the ZIP and install `app-debug.apk` on your Android phone.

This is an initial version. The equalizer controls are UI-only, and build verification is still needed.
